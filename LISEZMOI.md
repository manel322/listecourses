# Squelette de projet fwtozza

    npm install
    npm test          # prouve le catalogue et le composant d'exemple
    node server.js    # http://localhost:3000

Arborescence : `fw/` et `public/fw/` ne se touchent jamais. Écrivez vos contrats dans
`public/catalogs/app.catalog.js`, vos composants dans `components/` (serveur) et
`public/components/` (client), et composez dans `server.js` et `public/index.html`.

Le composant d'exemple (ping → pong) est à remplacer. Documentation : le site fwtozza.
